# Shizuka JWT Token Generator Website

Light Rainbow themed frontend for `https://jwt-api-by-shizuka.vercel.app/token`.

## Deploy on Vercel
1. Push all files to a GitHub repository.
2. Import the repository in Vercel.
3. Click **Deploy** (uses `vercel.json` automatically).

## Deploy on Render
1. Push all files to a GitHub repository.
2. In Render, select **New + -> Static Site** (or Blueprint using `render.yaml`).
3. Set **Publish Directory** to `.` and click **Create Static Site**.
